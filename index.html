Repositório de atualizações do CapivaraOS

Este é o repositório oficial de pacotes e atualizações do CapivaraOS (linha desktop / comunidade).

Você não precisa configurar nada. O pacote capivaraos-repos já vem instalado no sistema e aponta para cá: as atualizações chegam pelo dnf e pelo atualizador do seu ambiente.

No ar agora

  • Marsh, Pup e Snout — Fedora 45, x86_64
  • Canal stable, ligado por padrão
  • Canal testing, para quem acompanha o desenvolvimento, desligado por padrão

Integridade

Os pacotes e o índice do repositório são assinados com a nossa chave GPG. A confiança vem da assinatura, não do host: com gpgcheck e repo_gpgcheck ligados, o dnf recusa qualquer pacote ou metadado que não bata com a chave — mesmo que este servidor fosse comprometido.

Chave pública: RPM-GPG-KEY-capivaraos

Para conferir você mesmo que a chave é esta:

curl -O https://repo.capivaraos.org/RPM-GPG-KEY-capivaraos
gpg --show-keys --fingerprint RPM-GPG-KEY-capivaraos

English

CapivaraOS update repository

This is the official package and update repository for CapivaraOS (desktop / community line).

There is nothing to set up. The capivaraos-repos package ships with the system and already points here: updates arrive through dnf and through your desktop's own updater.

Live now

  • Marsh, Pup and Snout — Fedora 45, x86_64
  • stable channel, enabled by default
  • testing channel, for people following development, disabled by default

Integrity

Both the packages and the repository index are signed with our GPG key. Trust comes from the signature, not from the host: with gpgcheck and repo_gpgcheck enabled, dnf refuses any package or metadata that does not match the key — even if this server were compromised.

Public key: RPM-GPG-KEY-capivaraos
Fingerprint: 75FA 3340 40FD 0150 4AAD 9337 E07F 78EA 4070 11BD

To check the key yourself:

curl -O https://repo.capivaraos.org/RPM-GPG-KEY-capivaraos
gpg --show-keys --fingerprint RPM-GPG-KEY-capivaraos
